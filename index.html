My Second Program (C++)

This is a linear search I wrote in C++ last year in my programming class. It returns the index of the target, or -1 if it isn't found:

int linearSearch(int A[], int n, int target) {
    for (int i = 0; i < n; i++) {
        if (A[i] == target)
            return i;
    }
    return -1;
}
